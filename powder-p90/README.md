# 粉体粒径档表 · 筛分核对单与多批合并 P90 最紧界核算

按批号上传粉体粒径**档表**（连续排列、互不重叠的整数微米闭区间），同批可补报
同一组粒子的不同分档表（入库前做整体相容性校验）；质检员可登记**筛分核对单**，
把三个已入库批次定为原批、筛下批、筛上批并核对筛分关系；在网页勾选多批后，计算
合并后 **P90 的最紧上下界**，并各给出一份能真实取到该端点的**逐批粒径频数见证**。
全程按档运算，不逐粒展开，合计 10 亿粒也按档秒级完成。

## 网页演示流程

### A. 档表上传 / 补报

1. **上传**：批号 `B-ALPHA`，粘贴（每行 `lo hi count`，空格或逗号分隔）：
   ```
   0 99 400
   100 199 500
   ```
2. **相容补报**：同批号再贴一张更细的分档表，提示“补报成功”，该批现有 2 张档表：
   ```
   0 49 100
   50 99 300
   100 149 400
   150 199 100
   ```
3. **不相容补报（被拒绝、不入库）**：同批号贴
   ```
   0 49 450
   50 99 0
   100 199 450
   ```
   页面给出冲突切割点与原因；批次详情里仍是原来的 2 张档表，后续核算只按
   已入库档表进行。

### B. 筛分核对单（`scripts.seed` 已写入 S-FEED / S-UNDER / S-OVER / S-OTHER）

1. **登记**：在“② 登记筛分核对单”中选
   原批 `S-FEED`、筛下批 `S-UNDER`、筛上批 `S-OVER`，筛孔填 `100`，提交。
   页面提示“核对通过，登记成功：核对单 #1，筛孔 100 微米”。
   - 三个批号必须不同；筛孔只收正整数微米（`100.0`、`1e2`、`100微米` 均拒绝）。
   - 同一批只能登记在一张单上：再次登记会提示“已登记在核对单上”。
   - 核对口径：三批**全部已入库档表**须能由一次筛分同时得到；原批中粒径
     `<100` 的粒子全部归筛下批，其余（`≥100`）全部归筛上批。冲突时页面给出
     原因（如“筛上批只能含 ≥100 微米的粒子”“总粒数不守恒”），本次不写入。
   - 核对期间只做只读查询、不持写锁，其他批仍可正常补报。
2. **整张单复核的补报**：
   - 对 `S-FEED` 补报合法细分表 `0 49 250 / 50 99 350 / 100 199 400` →
     “补报成功……且核对单 #1 整张单复核通过”。
   - 对 `S-FEED` 补报 `0 99 400 / 100 199 600`：它与该批已入库粗档表**相容**，
     但使 `<100` 至多 400 粒、与筛下批 600 粒冲突，页面提示“补报后整张单核对
     不通过”并说明原因；本次不入库，档表数与核对单均不变。
   - 对未登记的 `S-OTHER` 补报不受核对单影响。

### C. 合并核算与拦截

- 勾选 `S-UNDER` + `S-OVER`（两个产物）→ 正常核算合并 P90（种子数据下为
  下界 150、上界 199 微米，总粒数 1000）。
- 勾选 `S-FEED` + `S-UNDER` 或 `S-FEED` + `S-OVER` → 被拦下并说明“原批不能与
  任一产物同时参与合并核算（总粒数会重复计算）”。
- 只勾 `S-FEED`，或 `S-FEED` + 未登记的 `S-OTHER` → 正常核算。

## 算法要点（按档计算，不展开粒子）

### 合并 P90 最紧界

对档表 T 记切割点 `cuts=[lo0, hi0+1, hi1+1, …]` 与档累计 `cum`。对任意整数
切割点 c，任一相容粒子组中“粒径 < c 的粒数”被夹在：

- `S_T(c)`：完全位于 c 左侧（`hi+1 ≤ c`）的档粒数和（下界）；
- `E_T(c)`：档起点 `lo < c` 的档粒数和（上界）。

一批所有档表的切割点取并集，该批的累计走廊为逐点
`L(j)=max_T S_T(c_j)`、`U(j)=min_T E_T(c_j)`。**多表相容 ⇔ 总粒数一致且
处处 L(j) ≤ U(j)**（在表自身切割点上 S=E，CDF 被钉死，走廊宽度只出现在档内）。

多批各批独立，合并走廊为各批 L/U 之和。设 `k=⌈0.9N⌉`：

- 最紧**下界** = 首个满足 `U(j+1) ≥ k` 的原子段 `[c_j,c_{j+1})` 的左端点；
- 最紧**上界** = 首个满足 `L(j+1) ≥ k` 的段的右端点 `c_{j+1}-1`。

见证（每批一份，合并后第 k 粒恰为端点）：

- 下界见证：段 j 放 `U(j+1)-U(j)` 粒、堆段左端（CDF 处处贴 U）；
- 上界见证：段 j 放 `L(j+1)-L(j)` 粒、堆段右端（CDF 处处贴 L）。

所有 S/E 序列由双指针线性归并得到，复杂度 O(表数 × (档数 + 全局切割点数))，
空间与档数同阶，与粒数无关。

### 筛分核对

设原批累计函数 `A(c)` = “原批中粒径 < c 的粒数”，`N_U`、`N_O` 为筛下、筛上批
总量。一次筛分成立 ⇔ 存在非递减的 A 同时满足：

- `L_F(c) ≤ A(c) ≤ U_F(c)`（原批全部档表）；
- `c ≤ 筛孔` 时 `L_U(c) ≤ A(c) ≤ U_U(c)`（筛下批全部档表），且筛上批累计为 0；
- `c = 筛孔` 时 `A(c) = N_U`（筛孔以下全部归筛下），故须 `N_F = N_U + N_O`；
- `c > 筛孔` 时 `N_U` 落在筛下批走廊内，且 `L_O(c) ≤ A(c)-N_U ≤ U_O(c)`。

在“三批档表全部切割点 ∪ {筛孔}”上逐点取满足下界的最小值（贪心）；L/U 单调，
贪心失败即不可行。复杂度 O(三批档数 + 切割点数)。

## 约束与语义

- 档：非负整数 `lo ≤ hi`，档间首尾相接、互不重叠；粒数非负，整表至少一粒；
- 允许零粒档；允许补报表用零粒尾档把覆盖范围往外扩（不要求新粒子）；
- 同批各表总粒数必须相同；冲突时整次补报拒绝，不写库。
- 筛分核对一律以**入库时**的档表与筛分关系为准；登记与补报都以全部已入库档表
  重算，任何冲突都整次拒绝、不写入。
- 一个批次最多登记在一张核对单上（数据库 UNIQUE 约束兜底并发）。
